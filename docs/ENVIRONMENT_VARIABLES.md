# Environment Variables Matrix — HookRelay

Configuration options available across runtime environments:

| Variable | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `NODE_ENV` | string | `production` | Node execution environment |
| `PORT` | number | `4040` | Default HTTP port for Web Studio |
| `DEBUG` | boolean | `false` | Enable verbose diagnostic logging |
| `CI` | boolean | `false` | Enables headless non-interactive terminal mode |
